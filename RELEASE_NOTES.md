# UniMarket – Final POE Release Notes

## Version 1.0 – November 2026

### Updates Since the Prototype

**1. Android Application**
- Improved navigation between marketplace screens.
- Updated login and registration error handling.
- Removed simulated authentication success when the API is unavailable.

**2. Language and Settings**
- Added Sepedi translation resources.
- Implemented English/Sepedi language selection.
- Added saved settings preferences.

**3. Backend Development**
- Developed an ASP.NET Core Web API for Firestore integration.
- Created a Firestore database for marketplace listings.
- Prepared Retrofit integration between the Android app and API.

**4. Development and Testing**
- Used GitHub branches and pull requests for team collaboration.
- Successfully built the Android application locally.
- Set up GitHub Actions for automated builds, with workflow fixes in progress.

### Innovative Features

UniMarket combines a student-focused second-hand marketplace with multilingual accessibility and planned offline synchronisation and cloud integration.

### Known Limitations

Backend authentication, Google SSO, push notifications and offline synchronisation require confirmation through final integration testing.
