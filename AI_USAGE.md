# AI Tools Usage Declaration

**Project:** UniMarket – Campus Marketplace Android Application

During the development of UniMarket, OpenAI's ChatGPT was used as a supporting tool to assist with understanding programming concepts, troubleshooting errors, code improvements and project documentation.

AI assistance included reviewing Kotlin authentication functions, identifying and correcting mock authentication behaviour, explaining Android API integration, and providing guidance on GitHub branches, pull requests and merge procedures.

ChatGPT was also used to interpret GitHub Actions build errors, assist with debugging and prepare project documentation, including the README and release notes.

The development team was responsible for implementing, reviewing, testing and integrating the application. AI-generated suggestions were evaluated against the project's requirements and tested where possible.

**AI tool referenced:** OpenAI. (2026). *ChatGPT*. https://chatgpt.com/
